# HARLAN HAWK — Official Author Website

This repository contains the English-only official website for HARLAN HAWK.

## Files
- `index.html` — website homepage
- `style.css` — website styling
- `brand-logo.png` — author logo
- `author-hero.jpg` — homepage author image
- `book-cover-en.jpg` — English book cover
- `social-preview.jpg` — social sharing / video poster image
- `TRAPPED_IN_A_MANS_BODY_Storyboard_Corrected_Final_ArticFoxMusic.mp4` — cinematic trailer
- `TRAPPED_IN_A_MANS_BODY_Trailer_ENGLISH_REPAIRED_FINAL.mp4` — English trailer

## Publish with GitHub Pages
1. Back up the current repository files.
2. Upload the files in this package to the repository root, replacing `index.html`, `style.css`, and the matching assets.
3. Commit the changes.
4. Wait for GitHub Pages to finish deploying, then refresh https://harlanhawk.github.io/.

The website now presents only the English edition of *TRAPPED IN A MAN'S BODY*.
